安裝擴充功能

免費開源的 Chromium 擴充功能

取得內嵌碼的那一刻， 貼文已經存好

在 Threads 貼文選單點「取得內嵌程式碼」，內嵌碼、內文、作者與發文時間就自動存進你的瀏覽器，隨時預覽、整理、匯出。

安裝擴充功能 GitHub 原始碼
  • 0 個外部相依套件 原生 JavaScript，不用建置就能載入
  • 3 種匯出格式 嵌入碼、精選資料、完整備份
  • 6×6 篩選與排序 依作者、標籤、失效狀態交叉整理
  • 8秒 可以反悔 刪除、批次刪除與清空都能復原

不用改變習慣，也不用多按按鈕

Threads 本來就有「取得內嵌程式碼」。擴充功能只在旁邊等著，對話框一出現，就把整篇貼文記下來。

  1. 打開內嵌對話框

    在貼文右上角的「⋯」選單點「取得內嵌程式碼」，就是平常嵌入貼文的步驟。

  2. 擷取並清洗內容

    從對話框挑出完整的 <blockquote> 內嵌碼，再擷取內文、作者、發文時間與標籤，順手濾掉介面文字。

  3. 存進你的瀏覽器

    寫入 chrome.storage.local 並跳出「內嵌程式碼已儲存」。之後從工具列的彈出視窗或全頁控制面板都找得到。

互動示範

只留下作者寫的字

按鈕、粉絲數與相對時間，常會混進擷取結果。這裡直接執行擴充功能 content.js 裡的清洗函式，改動原始文字，清洗結果會即時更新。

    工具列的彈出視窗適合快速查找，全頁控制面板負責預覽、批次處理與統計。收藏到數千篇，清單也是分批載入，打開與搜尋都不用等。

    不離開面板就能預覽

    以 Threads 官方的 658px 寬度載入原生卡片，高度自動貼合內容；也能切到「原始碼與中繼資料」。用 ← → 換篇，Esc 關閉。

    在背景逐篇更新

    重複使用同一個背景分頁依序載入，不會一次開一堆分頁。可以暫停、繼續或取消；結果每 20 篇寫回一次，期間在 Threads 新存的貼文也不會被蓋掉。

    刪錯了還能復原

    刪除、批次刪除與清除全部之後，8 秒內按「復原」就還原。

    標籤與作者排行

    統計最常出現的 15 個標籤與作者，點一下就篩選，再點一次取消。

    貼文消失也知道

    被刪除、轉私密或轉址的貼文會標成失效並記下原因，恢復後自動解除。

    勾選後批次處理

    批次更新、複製 Embed 或刪除；三種匯出也只會帶走勾選的貼文。沒勾選時，這些按鈕保持停用，鍵盤也按不到。

    只用鍵盤也行

    對話框會鎖定焦點，關閉後回到原本的按鈕；通知會被螢幕閱讀器念出來，也尊重「減少動態效果」設定。

    匯出成網站用得上的格式

    有勾選就只匯出勾選的貼文，沒勾選就匯出目前篩選後的清單。三種格式都是能直接引用的 JavaScript 檔；每段內嵌碼附帶的 <script> 會先移除，網頁只需載入一次 embed.js。

    threads-embed-codes-YYYY-MM-DD.js

    只有內嵌碼的字串陣列，單引號已跳脫。適合直接貼進靜態網頁，搭配一次 Threads 的 embed.js 就能顯示。

    適合手刻的個人網站、部落格文章

    const posts = [
    '<blockquote class="text-post-media" data-text-post-permalink="https://www.threads.com/@mochi.frontend/post/DQx7mK2pLsA" …>…</blockquote>',
    '<blockquote class="text-post-media" data-text-post-permalink="https://www.threads.com/@ts.daily.notes/post/DQv3Rn8eTqB" …>…</blockquote>'
];

    threads-featured-data-YYYY-MM-DD.js

    每篇貼文一個物件：內嵌碼、連結、作者、內文與標籤。作者會去掉開頭的 @，方便當作鍵值或顯示名稱。

    適合Threads-Featured-Posts 的資料來源

    const posts = [
    {
        "embedCode": "<blockquote class=\"text-post-media\" …>…</blockquote>",
        "postLink": "https://www.threads.com/@mochi.frontend/post/DQx7mK2pLsA",
        "author": "mochi.frontend",
        "content": "CSS :has() 真的改變了我寫表單的方式。\n勾選「需要發票」才展開統編欄位…",

            "前端技巧",
            "CSS"
        ]
    }
];

    threads-full-data-YYYY-MM-DD.js

    除了內嵌碼、連結、作者、內文與標籤，還保留發文時間、儲存時間與失效狀態。換電腦、清理之前或想留一份紀錄時用它。

    適合備份、搬家、災難還原

    資料只存在你的瀏覽器

    沒有伺服器、沒有帳號，也不收集使用紀錄。你存下的貼文只寫進本機，不會被傳到任何地方。

    API 權限

    storage
    讀寫本機的 chrome.storage.local，所有貼文都存在這裡。
    unlimitedStorage
    解除 chrome.storage.local 的 10MB 配額，收藏數千篇也不會寫入失敗。
    tabs
    更新貼文資料時，在背景開一個工作分頁逐篇載入，結束後關閉。
    scripting
    在那個工作分頁注入擷取腳本，讀回發文時間、內文與標籤。

    網站存取

    threads.com
    含 www。在貼文頁偵測內嵌對話框並擷取內容。
    threads.net
    含 www。同樣會擷取內容，即時預覽的官方內嵌框架也從這裡載入。

    內容安全政策

    script-src 'self'
    只執行擴充功能自帶的腳本，不載入任何遠端程式碼。
    frame-src
    預覽用的框架只允許 Threads 官方網域。

    嵌入碼評分

    對話框裡可能同時有純連結和完整內嵌碼。每個唯讀欄位依內容加權，分數最高的就是帶 data-text-post-permalink 的 blockquote。

    let score = value.length;
if (/data-text-post-permalink=/i.test(value)) score += 1000;
if (/<blockquote/i.test(value)) score += 500;
if (/threads\.com/i.test(value)) score += 100;

    保留換行的內文擷取

    只保留沒有被其他候選容器包住的最外層容器，再用 innerText 輸出。段落與 <br> 換行都留著，子節點也不會重複擷取。

    const topContainers = beforeReply.filter(el =>
  !beforeReply.some(other => other !== el && other.contains(el))
);

    單一工作分頁的循序佇列

    每一輪先檢查取消與暫停，再用同一個背景分頁載入下一篇，每篇最多等 60 秒，逾時只算失敗、不標成失效。結果每 20 篇、按下暫停或佇列結束時寫回一次，只寫這幾篇各自的紀錄並合併更新欄位；佇列期間被刪除的不會被寫回來，新存的貼文也不受影響。

  const tabId = await getOrCreateWorkerTab();

}

    預覽高度回報與來源驗證

    Threads 的內嵌頁不會回報高度，所以 content.js 也注入預覽框架，用 ResizeObserver 量 .Embed 的高度，有變化才用 postMessage 回傳。控制面板只接受官方網域的訊息。 

    function isAllowedEmbedOrigin(origin) {
  if (!origin) return false;
  try {
    const url = new URL(origin);
    const hostname = url.hostname.toLowerCase();
    const allowedDomains = ['threads.net', 'threads.com', 'instagram.com'];
    return allowedDomains.some(domain => hostname === domain || hostname.endsWith('.' + domain));
  } catch (_) {
    return false;
  }
}

    安裝

    四個步驟裝好

    以「載入未封裝項目」的方式安裝，支援 Manifest V3 的 Chromium 瀏覽器都能使用。

    1. 下載原始碼

      用 Git 複製專案，或下載 ZIP 後解壓縮。

      git clone https://github.com/Scorpio-meow/Threads-embedded-code.git
      下載 ZIP

    2. 開啟擴充功能管理頁

      在網址列貼上下面的網址；Edge 請改用 edge://extensions/。

      chrome://extensions/

    3. 開啟開發人員模式

      切換頁面右上角的「開發人員模式」開關。

    4. 載入未封裝項目

      點「載入未封裝項目」，選取含有 manifest.json 的專案資料夾，再把「Threads 程式碼儲存器」釘選到工具列。

    常見問題

    點了「取得內嵌程式碼」，卻沒有出現儲存提示？

    先確認已登入 Threads，未登入時官方對話框可能產生不了內嵌碼；網址也要是 threads.com 或 threads.net。如果開發者工具出現「Extension context invalidated」，代表擴充功能剛重新載入過，重新整理 Threads 頁面就會恢復。如果跳出「找不到可儲存的內嵌程式碼」，通常是 Threads 這次沒產生內嵌碼，關掉對話框再點一次「取得內嵌程式碼」就好。

    為什麼有些貼文被標成失效？

    背景更新時，如果貼文被刪除、帳號轉為私密、頁面不存在或網址被轉導，就會標記為失效並記下原因，例如 post-not-found 或 redirected。之後只要貼文恢復可讀，下次更新就會自動解除。載入超過 60 秒仍拿不到結果時，只會記為這次更新失敗，不會標成失效。

    Threads 改版後抓不到內容怎麼辦？

    擷取依賴 Threads 網頁的結構與 class 名稱，官方大幅改版時可能暫時失效。請到 GitHub Issues 回報，維護者會更新 content.js 裡的選擇器。

    最多可以存多少篇？

    chrome.storage.local 的預設配額是 10MB，每篇含官方內嵌碼約 3–4 KB，大約兩、三千篇就會用完。擴充功能宣告了 unlimitedStorage 權限解除這個上限，實際容量取決於磁碟空間。仍建議定期匯出完整備份。

    不小心刪錯或清空了怎麼辦？

    刪除、批次刪除與清除全部都能復原：畫面下方的提示會出現「復原」按鈕，8 秒內按下就還原。提示消失後就無法復原，所以清空前建議先匯出完整備份。

    資料會被上傳到任何地方嗎？

    不會。貼文只存在瀏覽器的 chrome.storage.local，擴充功能沒有自己的伺服器，也沒有任何追蹤或統計。需要連網的只有 Threads 相關功能（官方內嵌預覽與背景更新），以及介面使用的 Google Fonts 字型。

    手機可以用嗎？

    需要能安裝擴充功能的桌面版 Chromium 瀏覽器，例如 Chrome、Edge、Brave、Opera 或 Arc。
